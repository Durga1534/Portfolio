## 🖥️ Overview

A **premium, dark-themed developer portfolio** built to make a strong first impression with recruiters. Features glassmorphism UI, animated typewriter roles, bento-grid project layout, and smooth scroll interactions — all in a production-ready Next.js 15 application.

**Designed to be in the top 10% of developer portfolios.**

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repo
git clone https://github.com/Durga1534/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Add your EmailJS credentials (see below)

# Start dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Environment Variables

Create a `.env.local` file with your [EmailJS](https://www.emailjs.com/) credentials:

```env
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
```

## 📦 Build & Deploy

```bash
# Production build
npm run build

# Start production server
npm start
```

**Deploy to Vercel (recommended):**

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Durga1534/Portfolio)

> Add your `NEXT_PUBLIC_EMAILJS_*` environment variables in the Vercel dashboard under **Settings → Environment Variables**.

## 🎨 Design Decisions

- **Dark over light** — premium dark themes signal engineering maturity and design sensibility
- **Indigo/violet/cyan palette** — vibrant but professional, avoids the cliché neon-green "hacker" look
- **Glassmorphism** — depth and dimension without heavy background images
- **Framer Motion `layoutId`** — buttery smooth tab/nav transitions that elevate perceived quality
- **Bento grid** — differentiates the projects section from the ubiquitous uniform card grid
